# Forecast MVP

## Run locally

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

1. Create a GitHub repository named `forecast-mvp`.
2. Upload/push this project to the repository's `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions**.
5. Push the project (or re-run the workflow under the **Actions** tab).
6. After the workflow succeeds, open:

`https://YOUR-GITHUB-USERNAME.github.io/forecast-mvp/`

The Vite base path is already configured for the `forecast-mvp` repository.
